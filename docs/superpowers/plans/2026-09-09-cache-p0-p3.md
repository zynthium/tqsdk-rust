# 回测缓存 P0–P3 执行清单

状态：进行中。本文是执行记录；`docs/architecture/` 才是当前合同。

## 已批准决策

- Tick 采用稳定交易日级规范化，不保留旧 reader 随请求窗口变化的异常去重结果。
- Daily、Minute、Tick 共用 `TQHIST01` envelope、双提交槽、checksum、index/extent/slice 语义；codec 按数据族区分。
- `.tqdk`、`.tqmk`、`.tqbn` 保留为 family/layout hint；编码身份只由 magic/index 决定，不做无收益全盘改后缀。
- 真实默认缓存迁移必须停旧进程、先保留整代旧数据、离线验证、原子发布；旧 binary 回滚必须连同整代数据恢复。

## 真实缓存基线

- 默认目录：`/root/.tqsdk/data_series_1`；仅此处使用。
- 当前约 289,599 个 Tick `.tqbn`；已盘点 schema 3 文件均有 32-byte `TQTC` committed-prefix checkpoint。
- 约 286 个空 orphan lock；迁移不得把 lock 当数据文件。
- 只读 dry-run 与迁移前深度验证不得修改真实缓存。

## P0：中断恢复与写放大

- [x] Daily/Minute append 使用 committed prefix；中断只留下不可见 suffix，重启复用已提交进度。
- [x] Tick rows/coverage/provisional 以 checkpoint-confirmed prefix 为准；schema 3 缺失/损坏 checkpoint fail closed，schema 2 保留兼容扫描。
- [x] 多链接 data inode 写前 COW；已打开 reader 固定旧 inode；单链接保持快路径。
- [x] common container 双槽提交、候选验证、父目录 durability 与 orphan 排除。
- [x] fill 取消与 terminal 子窗口提交测试。

## P2：按实际规模重分区

- [x] Tick：当日热分区保持 trading-day 文件；封闭冷数据按交易月 pack。预计约 15,549 个冷 pack，历史盘点最大约 47.5 MiB、p99 约 18.9 MiB。
- [x] Minute：保留交易月文件。每合约每年最多 12 个文件，年包只会放大局部刷新、修复和锁冲突，不能解决当前规模瓶颈。
- [x] Daily：每合约全历史单文件，增量 append 最新日期，不重读全部 payload；doctor 才做全量深检。
- [x] Tick 月包保留 slice、coverage/finality/source/metadata identity，窄查询只解码相交 slice；范围 purge 重写月包但保留未命中交易日。
- [x] 月包先原子发布、后删除日文件；发布后月包即为权威，中断重跑只校验并删除被月包包含的残留日文件，绝不反向合并覆盖修订。

## P3：锁与性能门禁

- [x] 锁粒度匹配物理 mutation 单元：Tick 热日、Tick 冷月、Minute 月文件、Daily 合约文件。
- [x] lazy reader 从分区枚举到所有候选路径均已打开/固定持有根共享门禁；之后由 opened-file snapshot 固定内容。独立 append 仍可并发，迁移、月包封存、发布和破坏性 maintenance 使用根独占门禁。
- [ ] 建立真实规模 benchmark：启动 inventory、窄范围 query、每日增量、月/年 seal、doctor、迁移重启。
- [ ] 记录 FD 峰值、bytes read/written、write amplification、锁等待 p50/p95/p99、峰值 RSS；阈值写入 `docs/architecture/validation.md`。

## 提交与部署顺序

1. 按 P0、P1、P2、P3、文档/迁移运维分批提交；每批提交前运行 GitNexus change detection。
2. 完成 all-targets clippy、fmt、全 workspace 测试及一次只读架构复核。
3. 停止所有旧 reader/writer；确认默认 cache root 无活动 writer。
4. 创建并验证旧 binary 可读的完整 generation 备份。
5. 运行新 binary dry-run；容量估算、problem files、schema 分布均通过后才 apply。
6. apply 后 doctor、inventory、代表性 Tick/Minute/Daily query；保留 backup，不自动删除。
7. 安装新 binary 并保留旧 binary；观察稳定后另轮删除兼容代码与旧备份。
